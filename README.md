# AI Job Agent

AI Job Agent is a full-stack AI-powered job search and application assistant.

## Features

- User Authentication (JWT)
- Job Search
- Resume Upload & Parsing
- Resume Analysis using AI
- AI Cold Email Generation
- Job Match Recommendations
- Application Tracking Dashboard

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- bcrypt

### AI Service
- FastAPI
- LangChain
- Groq LLM

## Project Structure

```text
frontend/
backend/
ai/
```

## Run Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### AI Service

```bash
cd ai
pip install -r requirements.txt
python main.py
```
